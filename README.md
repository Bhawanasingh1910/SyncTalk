# SyncTalk

A full-stack real-time video conferencing platform built with **React, Node.js, Express, MongoDB, Socket.IO, and WebRTC**.

SyncTalk allows users to create and join meetings with real-time video, audio, messaging, and meeting history.

## Features

* 🔐 User registration and login
* 🎥 Real-time video calling
* 🎙️ Audio communication
* 💬 Real-time meeting chat
* 🔗 Create and join meetings using meeting codes
* 📋 Meeting activity/history
* 👥 Multi-user video meetings
* 🔄 Real-time communication using Socket.IO
* 🌐 Production deployment with Vercel and Render

## Tech Stack

**Frontend**

* React.js
* Material UI
* JavaScript
* WebRTC

**Backend**

* Node.js
* Express.js
* Socket.IO

**Database**

* MongoDB
* Mongoose

**Authentication**

* bcrypt
* Token-based authentication

**Deployment**

* Vercel — Frontend
* Render — Backend
